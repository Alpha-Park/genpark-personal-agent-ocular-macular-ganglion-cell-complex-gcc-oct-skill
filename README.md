# Ocular Macular Ganglion Cell Complex (GCC / GCIPL) Skill

A production-grade, zero-mock personal agent skill engineered for spectral-domain optical coherence tomography (SD-OCT) macular segmentation, retinal ganglion cell soma/dendrite profiling, and early glaucoma screening.

## Features
- **Deterministic Volumetric Analysis**: Computes average macular thickness, vertical hemifield asymmetry, and $FLV\% / GLV\%$ loss volumes.
- **Pre-Perimetric Glaucoma Sentinel**: Sensitive to the initial 30-50% loss of retinal ganglion cells that occurs before Humphrey visual field scotomas appear.
- **Pure Standard Library**: Zero external dependencies; fully portable for edge and clinical AI deployment.

## Clinical References
